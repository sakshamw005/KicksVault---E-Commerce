video 57 :

sessions stores objects (key-value pair) 

what is a session ?
When we request server , server responds with cookies also , cookies have particular session id , server allocated some memory at Server side storage for cookies to take some space .

and when we request nxt time , along with our request cookies saving our data also go to server .

to use session we have a npm package called 'express-session' , we install it 

after that we setup a basic server , 

const express = require('express') ;
const app = express() ;
const session = require('express-session') ;

app.use(session({
  secret: 'keyboard cat',
  resave: false,
  saveUninitialized: true,
  //cookie: { secure: true } //for https
}))

app.get('/' , (req,res)=>{
    res.send("Welcome to session") ;
})

app.listen(8080 , ()=>{
    console.log("server connected at port 8080") ;
    
})

in this when we access '/' , see cookies we get a session id 
http only flag is also set


after this we setup a /viewcount api , in this when we visit in a session multiple times from browser the count increases
but as soon as we refresh the server , the count restarts

app.get('/viewcount' , (req,res)=>{
    if(req.session.count){
        req.session.count+=1 ;
    }
    else{
        req.session.count = 1 ;
    }
    res.send(`you visited the site ${req.session.count} times`) ;
})

this shows that session is a server side storage based .
